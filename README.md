# Sessões de Cinema Comunitário

Aplicação Flutter criada para o trabalho de programação com foco em gestão de sessões de cinema comunitário.

## Funcionalidades

- Criar, listar, editar e remover sessões.
- Validar título, classificação, sala e quantidade de lugares.
- Selecionar classificação e sala com `DropdownButtonFormField`.
- Marcar a existência de debate com `SwitchListTile`.
- Buscar sessões pelo título.
- Filtrar por sala, classificação e existência de debate.
- Exibir estado vazio quando não houver resultados.

## Como executar

```bash
flutter pub get
flutter run
```

## Observação

O projeto foi organizado para facilitar a entrega ao professor e a revisão do código.
