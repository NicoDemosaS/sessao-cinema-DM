# Sessões de Cinema Comunitário

Projeto desenvolvido em Flutter para gerenciamento de sessões de cinema comunitário.

## Funcionalidades

- Cadastro, edição, exclusão e listagem de sessões.
- Validação de título, classificação, sala e quantidade de lugares.
- Busca por título e filtros por sala, classificação e debate.

## Execução

```bash
flutter pub get
flutter run
```
